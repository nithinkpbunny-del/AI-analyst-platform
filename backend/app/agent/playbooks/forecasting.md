# Playbook: forecast
1. Choose the grain from the question (month by default) and make sure the last period with data is complete.
2. forecast the metric; read the method, the 80% range and the backtest error.
3. Answer with the expected value and the range, never a single number alone. Name the method and the backtest
   error (MAPE) in data_notes, and the assumption that the past pattern continues (festive season included).
4. If history is short (less than two seasons), say the forecast is rough.
